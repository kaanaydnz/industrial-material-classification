# AI Usage

## Tools Used
- **ChatGPT:** Used throughout development for coding assistance, UI/UX design ideas, mock API implementation, sample data generation, test planning, and debugging.

## Representative Prompts
- *"Help me implement a mock API with asynchronous requests, loading states, and error handling."*
- *"Generate a large sample dataset of industrial projects and materials for testing tables, search, and filters."*
- *"Suggest test cases for draft autosave and classification workflows."*
- *"Review the dashboard layout and suggest improvements to the user experience."*

## Accepted and Rejected Suggestions
AI suggestions helped shape the mock API, sample datasets, and UI design. Suggestions that fit the project requirements were adapted into the implementation. Others were modified or discarded when they did not fit the existing code structure or intended workflow.

## Code Verification
AI-generated code was reviewed and adapted to the existing React and TypeScript codebase. I ran the application locally to check the UI and functionality, and used build and test commands to identify potential errors where applicable. I also checked that the mock data and API behavior supported the intended workflows.
